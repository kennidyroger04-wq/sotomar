# Recursos Godot

- `tilesets/fimbria_ground.tres`: TileSet de seis materiais provisórios usado na cena principal.
- `tilesets/fimbria_art_demo.tres`: TileSet de 23 tiles originais ilustrados do protótipo G03; usado somente na cena de demonstração.
- `animations/wayfarer_v1.tres`: SpriteFrames do personagem provisório ilustrado G03, 8 animações (quatro vistas × idle/walk) com quatro quadros cada.
- `art_pack_g03.json`: dimensões, fontes, pivôs, regiões e animações do pacote.

O script `godot/tools/build_art_demo_resources.gd` regenera os dois recursos binários do Godot após atualizar PNGs.
