# Animation resources

`wayfarer_v1.tres` is generated from the 8×4 PNG spritesheet. Each 128×160 frame uses pivot `(64,152)`, 4 fps idle and 8 fps walk. Directions are row-major `se`, `sw`, `nw`, `ne`; each row has idle columns 0–3 and walk columns 4–7. The JSON mirror and frame rectangles are in `resources/art_pack_g03.json`.
