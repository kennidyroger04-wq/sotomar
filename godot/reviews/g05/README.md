# Revisão visual G05

Regerar imagens estáticas e GIFs (Pillow necessário):

```sh
python3 godot/tools/review_combat_art_g05.py
```

Pranchas: `wayfarer_animations.png`, `moss_raider_animations.png`, `equipment_layers.png`, `character_proportions.png`, `combat_sequences.png` e `combat_demo_static.png`. GIFs SE: ataque/conjuração Wayfarer e caminhada/ataque do Saqueador. Ver `review_index.json` para índice completo.

As composições são prévias de revisão; a captura do mapa e a sincronização real devem ser confirmadas abrindo `godot/scenes/combat_art_demo.tscn` no Godot Desktop. Cena interativa: `Tab` personagem, setas orientação, `1`–`7` ação, `G` equipamento, `F` efeito e `Espaço` repetir.
