# Briefs de produção G18C

Os textos abaixo registram a intenção dada ao gerador para reprodução e revisão. São briefings de interpretação visual, não declarações de cânone.

## Cascudo-de-cal — prancha idle

> Create an original polished 2D isometric fantasy creature character sprite sheet for a small burrowing limestone armadillo-beetle creature, canonical working name Cascudo-de-cal. This is original Sotomar/Fimbria game art, not based on any existing game. Use expressive hand-painted game illustration, bright but earthy palette, strong clean silhouette, dark warm outline, subtle ambient occlusion. Transparent background. Strict sheet layout 4 columns x 4 rows, each cell 128x160 pixels, identical scale and consistent feet/base pivot at x=64 y=152. The columns show four distinct isometric orientations (front, left, back, right). Rows are subtle idle loop frames 1-4 with tiny breathing/antenna changes. Whole sheet exactly 512x640, no grid lines, no labels, no shadows extending outside each cell. Creature: squat plated beetle with pale chalk-limestone segmented shell, tiny sturdy legs, ochre markings, small curious eyes, no weapons, recognizable from every direction. Keep each character fully inside its own cell with generous transparent margins.

O gerador não obedeceu à dimensão solicitada e emitiu uma prancha 1122×1402. O runtime usa regiões 280×350 e o relatório registra essa limitação.

## Casa de cal de Caieira

> One original 2D isometric fantasy village cottage asset for the game Sotomar/Fimbria. A small inhabited cottage in the village of Caieira, approachable and handcrafted, irregular pale limewashed stone walls, timber-framed warm ochre roof with subtle clay shingles, small dark oak door and one softly lit window, tiny bundles of dry herbs by the door. Strong readable silhouette, detailed illustrated game sprite, warm bright colors, clean brown outlines, crisp pixel-art-friendly edges with painterly texture, consistent soft light from upper left. Show one three-quarter isometric view with front and right side visible, orthographic, no perspective distortion. Transparent background. Full building including chimney and ground shadow fits within canvas, feet/base point centered at bottom. No people, no text, no logos, no extra objects, no sheet layout. Original visual design only.

A fonte não especifica essa arquitetura; ela é uma proposta visual para revisão.

## Mira — idle direcional

> Create original Sotomar/Fimbria 2D isometric NPC character art: Mira, the road guard of Caieira. This is a visual interpretation based on the documented job as a guard; the canon does not specify her face, armor, or clothing. Mature, capable, approachable village watchwoman, practical teal-and-ochre padded travel clothes, a small round wooden buckler and brass road badge, tied dark hair, confident kind expression. Keep original design, no resemblance to any existing game character. Match a richly illustrated, hand-painted fantasy RPG sprite style with warm brown contour, clear color blocks, subtle fabric/leather detail and soft light from upper left. Transparent background. Sprite sheet layout 4 columns by 4 rows: columns are front, left, back, right isometric orientations; each row is a tiny idle pose variation. Equal visual scale, feet on a consistent baseline, full character and buckler inside every cell, no labels, no gridlines, no extra characters or objects. Intended runtime region 280x350 per cell. Full sheet 1120x1400 pixels.

O gerador emitiu 1122×1402 RGBA (regiões de runtime 280×350). O equipamento, rosto e uniforme são propostas visuais, não traços canônicos.
