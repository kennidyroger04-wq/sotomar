# Fontes de arte G06

Os sete masters `male_warrior_{idle,walk,attack,hurt,defend,cast,death}_master.png` são folhas originais 4×4: linhas NE/SE/SW/NW, quatro quadros em sequência por orientação. `male_equipment_master.png` reúne as quatro vistas da espada e do escudo. `male_warrior_atlas_master.png` é apenas a primeira prancha conceitual da missão, sem uso no pacote final.

As fontes foram criadas para Sotomar/Fímbria. Não contêm ou derivam de recursos oficiais de Dofus. Para normalizar dimensões/transparência e registrar regiões, execute `python3 godot/tools/build_character_art_g06.py`. As fontes permanecem separadas dos PNGs runtime para permitir nova exportação sem perder a origem.
